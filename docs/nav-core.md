# 导航核心实现说明

## 坐标、单位和误差约定

导航系NED：北、东、地；机体系FRD：前、右、下。位置为纬经度rad/椭球高m，速度m/s，陀螺rad/s，加计为比力m/s²，时间为MCU单调微秒。`q_nb`将机体系向量旋到导航系；四元数顺序w,x,y,z。相机二维平面速度采用NED，仅观测北/东。

20维误差状态依次为：位置0–2、速度3–5、导航系左乘姿态6–8、陀螺零偏9–11、加计零偏12–14、水平风15–16、气压高度偏差17、VO尺度18、磁航向偏差19。误差定义true−nominal：`C_true=Exp(δθ)C_nominal`，状态注入与误差动力学使用同一符号。

## 机械编排和滤波

`propagateStrapdown`使用地球自转、牵连角速度、Somigliana正常重力、姿态中点比力与梯形位置积分。默认400Hz。纬度绝对值必须小于89.5°，当前NED编排不支持极区。

协方差默认100Hz预测，`Φ≈I+FΔt`并保留离散加计噪声的位置/速度交叉项。风、气压偏差、磁偏差采用一阶衰减，零偏/尺度采用随机游走。该线性模型保留方案中的主要误差耦合，没有宣称包含全部长航程高阶地球项、杆臂、圆锥/划桨、温漂、振动整流或时间相关图像噪声。

支持位置、NED速度、机体速度、真空速、气压高度、磁航向、雷达高/DEM。位置量测协方差为NED m²，与输入经纬度rad单位不同，不能用纬经度角方差直接填入。VO的协方差必须与声明的速度坐标系相同。二维NED视觉速度含VO尺度状态，三维机体速度还含姿态雅可比；GNSS速度不含VO尺度。

更新前检查量测维数、有限值与协方差正定性；使用99.9%卡方门限1/2/3维10.8276/13.8155/16.2662。Joseph更新和左乘姿态误差reset保持数值稳定。被拒绝的量测不更新模式的“最近成功修正”时间。

`horizontal_sigma_m=sqrt(P_NN+P_EE)`是水平误差二阶矩对应的径向RMS尺度，**不是CEP，也不是95%误差**。输出此值与垂直标准差、模式和健康位，实测精度需用独立真值评估。

## 时延量测

256个100Hz名义状态覆盖约2.56秒；默认最大量测年龄2秒。量测时间为曝光中点而非计算完成/网络接收时刻。历史位置、速度和四元数插值后计算新息与H，修正应用到当前状态，同时重基准历史以避免重复吸收旧残差。

这是短延迟近似：未保存完整历史协方差、状态转移和互协方差，没有重放全部后续量测，也不是随机克隆。高动态、大延迟或强相关图像输出必须另行升级OOSM/克隆机制。单目VO输出还依赖所用高度和导航姿态先验，现实中存在相关误差，不能仅靠合成测试认定协方差已准确。

## 输出、模式和故障

输出与视觉修正解耦；默认每400Hz IMU推进触发30Hz输出。期限从初始化epoch和输出计数直接计算，避免浮点逐次累加导致节拍漂移。调用者须及时消费`takeOutput`，当前接口是最新输出而不是无限缓存。

M0为2秒内成功GNSS位置；M1为30秒内成功视觉位置；M2为30秒内成功地形位置；否则M3推算。水平径向sigma超过300m进入M4重捕获。模式代表量测可用性，不等于完整航空完好性认证。

未来、过旧、同源同类重复/倒退量测拒绝。IMU倒退或非有限样本拒绝；连续时间缺口超过默认50ms时明确锁定`FilterInvalid`、清待输出并退出GNSS模式，保存的状态时间不假装向前推进。该情形须由上层重新对准后，在暂停相关任务/ISR条件下调用`initialize`恢复；飞控桥对健康异常或0.5秒无新帧停止发送。

协方差配置频率限定20–400Hz，避免超过当前离散预测步长；目标板仍须测实际周期/WCET。默认30Hz要求IMU真实供给足够且NavTask按时调度。

## 内存和任务边界

核心定长容器、不调用堆分配、编译禁异常/RTTI。宿主测试实测`sizeof(NavCore)=49080`字节，导航推进/量测更新期间new调用数为0。GNU13 `-O2 -fstack-usage`的预测/更新单函数栈约19.7/28.9KB；目标ARM编译器可能不同。对象和队列应静态放置，RTOS任务栈必须按目标报告和high-water mark校核。

只有NavTask写NavCore。每个SPSC队列只能一个生产者；多个传感器任务须分别建队列，不能把SPSC作为MPSC使用。`DemView`不拥有高程内存，调用者须保证连续数组至少有rows×cols元素且全程有效；查询拒绝NaN元数据/出界，不执行外推。
