# UAV Navigation 2 实现规格

本工程按上传的总体、硬件、软件方案实现独立导航软件。目标是可编译、可测试、可运行的宿主机工程，以及可接入 STM32H743、Jetson 和飞控的边界接口。用户已明确授权按附件实施并提交 voilalz/uav-navigation2；沿用附件设计，无需重新选择架构。

## 结构与坐标

- `nav/`：C++17 固定大小数学库、WGS-84 NED 捷联、20 维 ESKF、时延历史、IMU 阵列、模式、C99 协议、仿真与回放。
- `companion/`：真正可执行的 CPU 图像定位基线、单目平面 VO、地形网格配准、瓦片访问。深度网络权重与 TensorRT 引擎是外部可替换后端，未提供时不生成伪量测。
- `firmware/`：设备总线接口、传感器解码、任务队列、时间同步与 STM32/FreeRTOS 移植入口。具体 PCB 引脚与厂商 SDK 由目标板工程提供。
- `integration/`：独立串口导航接收与 MAVLink GPS_INPUT 桥接；ArduPilot 原生后端是版本相关集成工作，不在未经测试时宣称已被上游飞控接受。
- `tools/`：影像瓦片打包、日志评估、Monte Carlo 与误差预算。
- 导航坐标 NED（北、东、地），机体系 FRD（前、右、下），SI 单位。纬经度核心使用 rad，协议使用 deg；高度为椭球高，地图必须统一高度基准。
- 四元数 `q_nb` 把机体系变换到 NED；姿态误差为导航系左乘，误差统一为 true−nominal。偏差状态与修正符号据此统一。
- MCU 是微秒时钟主站。图像量测 timestamp 是曝光中点，拒绝未来/过旧时间、无效数值、非正定协方差。

## 核心验收

1. 导航核心不调用堆分配，编译禁异常/RTTI。状态维数 20：p/v/theta/bg/ba/风NE/气压偏差/VO尺度/磁航向偏差。
2. 捷联保持 WGS-84 重力、地球自转、牵连角速度；400 Hz 推算，100 Hz 协方差传播，30 Hz 可配置输出。
3. 位置、GNSS 速度、VO 机体速度、空速、气压、磁航向、雷达高/DEM 量测；Joseph 更新、卡方门限、姿态协方差 reset。
4. 2.56 s 名义状态历史用于延迟新息；修正同步重基准历史，避免重复吸收同一残差。该方式是小延迟近似，非随机克隆/全状态回放，NIS/NEES 如实评估。
5. M0 GNSS / M1 视觉 / M2 地形 / M3 推算 / M4 重捕获按被接受的量测和协方差进入；未经门限接受的量测不更新模式。
6. 协议显式小端序列化、CRC16、流式重同步；禁止直接发内存结构；队列溢出有计数。
7. 静止、转弯、时延、离群、丢失、恢复及各算法退化有回归；真值与估计日志分开。
8. 模块实施后运行 CMake/CTest，短与长仿真；只报告本次真实生成的结果，不引用附件声称的历史结果。

## 已确定的交付界限

可复现宿主机工程是本次实际验证对象。没有真实传感器、相机 SDK、神经网络权重、目标板 BSP、ArduPilot 源码和试飞日志，不能验证实机时延、烧录固件、跨季节/红外匹配、机载精度或飞行合格性。交付中逐项标明实现、适配入口和未验证部分，不把桩函数说成完成算法。
