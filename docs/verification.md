# 本次验证与交付范围（2026-10-12）

本报告对应新建工程v0.1.0，所有下列数字来自本次实际命令运行。`docs/source/`保留上传原稿，原稿中的历史代码路径和结果不作为本次验收证据。

## 构建与回归

环境：Linux x86_64，GNU C/C++ 13.3，CMake 4.4.4，Python 3.12.14；编译器支持C99/C++17。核心禁异常/RTTI，默认无需额外图像/数学库。具体CMake/Python版本见实际环境，最低项目要求为CMake3.20/C++17。

```sh
cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release
cmake --build build-release --parallel 4
ctest --test-dir build-release --output-on-failure
```

结果：**15/15组通过**。覆盖实际NCC→协议→MCU ESKF链路、在线/离线回放一致、静止惯导与输出节拍、量测与雅可比、协议损坏/重同步/全部消息、IMU阵列/队列/TERCOM、故障/无堆分配、视觉算法及演示、参考库/图像CLI、传感器/时钟、MCU任务运行时与飞控桥。

Python飞控与视觉协议测试合计16例通过。图像建库及回放CLI测试在`reference_tools`组内运行，不是只验证接口返回值。固定芯片帧、CRC黄金向量、独立数值差分、真值对齐和恢复故障均有具体断言。

```sh
cmake -S . -B build-sanitized -DCMAKE_BUILD_TYPE=Debug -DNAV_SANITIZE=ON
cmake --build build-sanitized --parallel 4
ASAN_OPTIONS=detect_leaks=0 ctest --test-dir build-sanitized --output-on-failure
```

结果：**15/15组通过**，地址与未定义行为检查启用。当前容器的LeakSanitizer无法读取进程task/ptrace，故关闭该项；不能声称已完成泄漏检测。导航核心单独检测new调用数为0，且库使用定长容器；这与整个视觉主机程序的内存证明不同。

代码审查独立检查了导航模型、时延、输入、协议、固件和视觉接口。初轮指出的异常未来量测阻塞、长IMU缺口失效语义、DEM非有限元数据、二维VO坐标系和栈预算已修正并加回归；最终CLI、发送器与文档收尾由作者检查并通过上述全工程测试。未把该审查称为目标板/飞行认证。

## 数字仿真

真值来自独立解析的速度/姿态/转弯/爬升函数，IMU由逆动力学生成；没有直接用同一个捷联函数制造真值。地球/大地坐标工具仍共享，故存在公共模型限制。加入商用MEMS级零偏/噪声/比例因子、VO0.8%尺度、磁0.5°偏差、气压25m偏差、视觉250ms与地形400ms延迟、短VO中断、120秒绝对修正中断和2km级错误位置。

| 场景 | 时长/输出次数 | 水平RMS | 水平95% | 水平最大值 |
|---|---:|---:|---:|---:|
| 完整组合，seed1 | 1200s / 36000 | 9.897m | 16.762m | 25.461m |
| 无绝对修正，相对辅助，seed1 | 1200s / 36000 | 372.303m | 567.502m | 630.911m |
| 惯导+气压阻尼，seed1 | 1200s / 36000 | 12258.362m | 18567.053m | 19917.989m |
| 完整组合，600km级，seed1 | 3600s / 108000 | 9.513m | 16.676m | 25.461m |

这些场景均实际为30.0Hz。完整组合1200秒seed1注入1次错误位置、拒绝1次；3600秒注入8次、拒绝8次。

100个随机种子，每次1200秒/约200km：

- 平均水平RMS **10.2465m**，单次RMS **7.2519–13.9750m**。
- 各次水平95%误差的最坏值 **33.9173m**；各次瞬时水平误差的最坏值 **57.0807m**。
- 所有运行输出 **30Hz**；累计 **168/168** 个注入错误位置被拒绝。
- 位置三维NEES均值 **2.8642**；这是位置子状态统计，未声称全20维一致性成立。
- NIS汇总混合1/2/3维且经过门限选择，不能直接和单一χ²期望比较。本工程记录每次运行汇总，未完成分量测/时段的正式置信区间验收。

完整结果：`docs/validation/monte-carlo-100.json`与四个场景summary。60秒在线日志回放1800行，各共同状态/健康字段的最大数值差为0；独立`analyze_log.py`只在时间对齐的真值存在时报告定位精度。

## 图像与协议衔接

实际运行生成PGM/DSM → 参考瓦片打包/哈希 → 三帧正射与NCC → 两次二维VO → DSM注册。图像CLI输出3个有效图像位置、2个有效VO和1个DSM注册；发送器只把可解释的绝对位置与二维NED速度编码，产生5个有效MCU帧，拒绝数0。相对DSM修正未经先验关联时不会被伪装成绝对高度量测。
